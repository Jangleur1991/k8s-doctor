# Gralde folder and files structure

## What
What is the concept? Two or three sentences.
What files does usually exists if you use gradle instead of maven for a java project.
There are always at least three files: the settings.gradle, the build.gradle and
the gradlew (which is not a file but a wrapper used to execute gradle build).

## Why
What problem does it solve?
Gradle is used as an alternative to maven. The knowledge of the
exists gradle files and their purpose is the basis for working with
gradle as build tool in any java project.
